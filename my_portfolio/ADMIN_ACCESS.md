# Admin panel access

The admin panel is **not linked** from the public site. Use this URL to manage your portfolio:

## Admin panel URL

**Local (development):**
```
http://localhost:5176/admin
```
(Use the port shown when you run `npm run dev`.)

**Production (after deploy):**
```
https://your-domain.com/admin
```

Bookmark this link or save it somewhere private. Only you (with your Supabase login) can use the admin panel.
